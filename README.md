# My Task List

## Name
Daniel Nwoye

## Application Name
My Task List

## Description
My Task List is a simple interactive web application that allows users to add and manage tasks. Users can enter a task, select a priority, mark a task as completed, and delete tasks.

## How to Run
1. Open the project folder.
2. Open the index.html file in a web browser.
3. Enter a task and select a priority.
4. Click Add Task to add the task.

## Known Problems
Tasks are not saved when the webpage is refreshed.
